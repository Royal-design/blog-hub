# 🚀 Blog Hub

A modern, responsive full-stack blogging platform built for seamless content creation, discovery, and community engagement.

🌐 **Live Demo:** [https://my-blog-hub.vercel.app/](https://my-blog-hub.vercel.app/)

---

## ✨ Features

- **📱 Mobile-First Responsive Design:**
  - Floating bottom navigation bar with glassmorphic `backdrop-blur-xl` effect.
  - Dedicated **Admin Panel** tab dynamically available for admin users on mobile & desktop.
  - Slide-up drawer navigation menu for quick access to all pages.

- **✍️ Story & Content Creation:**
  - Rich markdown/text editing and publishing workflow.
  - Categorization, tagging, and bookmarking functionality.

- **👥 Social & Community:**
  - Follow / Unfollow authors and personalize your home feed.
  - Explore trending stories, popular categories, and tags.

- **🛡️ Admin Management System:**
  - Comprehensive admin dashboard to monitor posts, users, categories, and site statistics.

- **🎨 Themes & Personalization:**
  - Full Dark/Light mode support with smooth color transitions and modern typography.

---

## 🛠️ Tech Stack

- **Frontend:** React 19, TypeScript, Vite, TailwindCSS v4, Lucide Icons, React Router v7
- **State Management & Data Fetching:** Zustand, TanStack React Query v5
- **Backend:** Node.js, Express, PostgreSQL
- **Deployment:** Vercel

## 🚀 Getting Started

### Prerequisites
- Node.js (v18+ recommended)
- npm or pnpm

### Installation

1. **Clone the repository:**
   ```bash
   git clone https://github.com/Royal-design/blog-hub.git
   cd blog-hub
   ```

2. **Install dependencies:**
   ```bash
   # Install root dependencies
   npm install

   # Install frontend web dependencies
   cd web
   npm install
   ```

3. **Run locally:**
   ```bash
   # From root directory
   npm run dev
   ```
